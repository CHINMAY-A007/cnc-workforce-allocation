# Presenter Cheat Sheet (1 page)

**Start:** Home → **"Start the 2-minute demo"** (resets clean data, highlights Step 1). All data labeled **"Demo data — Sample CNC Works, Bangalore"**.

1. Home: one-line value proposition + Start demo button + 5-step guided bar (current step highlighted, Next button). Open the collapsible **Presenter notes** panel.
2. Orders and Tasks: create an urgent order, note "Needs titanium, certified inspector only, surface finish N6". Show parser result + rejected phrases. Generate tasks. Show dependency flow.
3. Workforce and Skill Matrix: heatmap; point out expired certs (E01, E10, E07's CMM).
4. AI Allocation Proposal: Balanced preset → **Generate Schedule**. Show "Solved in Xs", no violations. Open "Why this person?" and conflict panel.
5. Schedule Gantt: toggle Employee / Work Center; filter by order.
6. Approval: reassign one task (reason required), lock two, approve. Audit log updates, alert fires.
7. My Tasks: switch role to Worker; show large Start / Complete / Report Issue buttons.
8. Live Progress and Alerts: Simulate absence → approve before/after diff (locked untouched). Then "Run impossible case" → zero-eligibility tasks + options. No override exists.
9. Reports: utilization, bottleneck, planned vs actual, on-time %.
10. Audit and Settings: audit log, weights, requirements coverage.

**Reset anytime:** "Start the 2-minute demo" restores clean seeded data.
